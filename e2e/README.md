# Airstream E2E suite

Black-box tests against `target/release/airstream.exe` and a **mock Google Cast receiver**
(CASTV2 over TLS, `lib/mock_receiver.py`). Nothing touches the real `%LOCALAPPDATA%\Airstream`:
each test starts the backend headless with its own `LOCALAPPDATA` under `e2e/.work/`.

## Run

```
cargo build --release          # if target/release/airstream.exe is missing
python e2e/run_all.py          # all tests, ~2 min, exit code != 0 on failure
uv run --with playwright python e2e/test_ui_play.py   # a single test
```

Needs on PATH: `ffmpeg`/`ffprobe`, `openssl` (git-bash's is fine), `uv` (for Playwright; Edge is used, headless).

## Tests

| file | checks |
|---|---|
| `test_cast_resilience.py` | warm channel doesn't launch; Play/Play again; Stop never auto-relaunches; silent player close → `transport play` 409 → Play relaunches; half-open socket → reconnect < 8 s; TV off → 502 < 15 s |
| `test_audio_compat.py` | no-Dolby receiver: E-AC-3 5.1 → AAC 6ch with bit-identical video; AAC source untouched |
| `test_ui_play.py` | UI Play button, relaunch after silent close, click spam → exactly one LOAD |

Tests run sequentially: the mock eureka endpoint must bind `127.0.0.1:8443` (fixed by the app).
Fixtures (60 s synthetic media, Thai SRT) are generated by `fixtures/make_fixtures.py` into `.work/media`.
